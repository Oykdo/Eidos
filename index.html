Pourquoi des symboles plutôt que des lettres ?

Une adresse est un très long nombre. Écrite en lettres et chiffres, une erreur de copie passe inaperçue. Ici chaque symbole empile trois figures — un cercle, un croissant, une croix — et les quatre derniers, en doré, contrôlent tous les autres. Si un seul symbole change, la vérification le détecte.

Pourquoi une adresse par paiement ?

Le code secret d'une adresse ne peut servir qu'une seule fois. C'est ce qui rend Eidos résistant aux futurs ordinateurs quantiques. Créez donc une adresse neuve chaque fois que vous attendez un paiement.

Ai-je perdu quelque chose en fermant la page ?

Si vous avez recopié le code secret, non. Rien n'est stocké sur cet appareil ni envoyé sur internet : tout est calculé dans votre navigateur. Sans le code secret, en revanche, l'adresse est irrécupérable.
